# Codex CLI

**What it is** — OpenAI's Codex CLI (`@openai/codex`, binary `codex`), used as an
**adversarial reviewer**: Claude writes the spec or the code, Codex reviews it, Claude
verifies every checkable claim before accepting anything.

**Where it lives** — Binary and auth are **per-machine and not synced** — verify
rather than assume. Check `codex --version` and `codex login status`. Credentials in
`~/.codex/auth.json` (ChatGPT login). Config is generated by `~/codex-ops-kit`
(`slaguru666/codex-ops-kit`) — **edit the templates there, not the live files**, or
the next install overwrites them. Profiles: `codex --profile economy|balanced|deep`.

**Current state** — In use across RingBRP, Corkboard and Loom.

**Next steps** — none.

**Key decisions**
- The method that works: Claude writes, Codex reviews adversarially, Claude
  re-verifies both sides. Across six RingBRP rounds every tested Codex claim held up
  — but Claude's own recomputation caught four wrong probabilities Claude had
  published. **Verify both sides.**
- Codex has also called a documented, deliberate design choice a bug. Weigh its
  findings against the code comments.

**Gotchas**
- `codex exec "<prompt>" < /dev/null` — it blocks on stdin otherwise.
- Add `--skip-git-repo-check` outside a git repo.
- `install.sh` only installs the binary when npm is already present; a machine
  without Node gets a warning and nothing else. Install Node first.
- A valid `auth.json` can exist even when the binary is missing — only run
  `codex login --device-auth` if `codex login status` says logged out.
