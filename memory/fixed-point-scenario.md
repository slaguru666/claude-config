FIXED POINT is a Custodians (RingBRP) crossing case at
`~/FoundryVTT/Data/systems/ringbrp/docs/scenarios/FIXED_POINT.md`. Earth's tilt is walking; the
cause is a row something filed in a Ringworld station-keeping almanac, and the fix is a pen.

**v2.0 (4 Nov 2026) is the model for the house format going forward** — the first scenario
written to [[rpg-skill]]'s `references/readable-scenarios.md`. Shape on page one, handouts named
in prose with codes only in the handout table, one bold label per block, metadata at the back.
7,388 words.

**Gotchas that cost time:**
- The arch renders at night, not in daylight — a description of faintness renders as absence.
- `&ldquo;`/`&rdquo;` in handout HTML break `check-handouts`; use literal quote characters.
- Printed page count tracks the number of `##` sections, not the prose: `make-pdf` starts each
  one on a fresh page. Measure words, or pass `--compact`.
- `make-pdf` supports neither fenced code blocks nor markdown images, so a diagram has to live
  in the handout pack HTML (FP-H00, the GM flow sheet).

**Still open:** no desk pass. The forty minutes of not knowing in Act Two is the whole case and
is unmeasured.
